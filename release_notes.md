# Abaqus语言切换工具 v1.0.0

## 中文说明

这是Abaqus语言切换工具的首个正式版本，可以帮助Abaqus用户快速切换界面语言（中英文）而无需修改系统区域设置。

### 功能特点

- 支持快速切换Abaqus界面语言（中文/英文）
- 无需修改Windows系统区域设置
- 提供配置文件自动备份功能
- 支持管理多个Abaqus安装路径
- 可直接运行Python源代码或使用打包的exe文件

### 使用方法

1. 下载exe文件
2. 以管理员身份运行
3. 按照界面提示操作，选择所需的语言

## English Description

This is the first official release of the Abaqus Language Switcher, which helps Abaqus users quickly switch interface languages (Chinese/English) without modifying system regional settings.

### Features

- Fast switching of Abaqus interface language (Chinese/English)
- No need to modify Windows system regional settings
- Automatic backup of configuration files
- Support for managing multiple Abaqus installation paths
- Can run directly from Python source code or using the packaged exe file

### Usage

1. Download the exe file
2. Run as administrator
3. Follow the on-screen prompts and select the desired language
